Place custom SVG icons for the icon browser in this folder.

Recommended structure:
- `custom/<theme>/<icon-name>.svg`
- or `custom/<style>/<icon-name>.svg`

Notes:
- Use SVG files only.
- Prefer square viewboxes for consistent preview sizing.
- Avoid brand logos unless you have the right to use them.
- The 65 existing icons were generated with an AI image-generation system at
  the direction of the project maintainer. The specific model, prompts, and
  per-file generation dates were not retained. No external icon files are known
  to have been imported into this collection.
- To the extent that copyrightable human selection, arrangement, or modification
  is present and controlled by the project maintainer, those contributions are
  offered under the recorded MIT license (bundled as Resources/IconLibrary/LICENSES/Project-Assets-MIT.txt). No exclusive copyright is claimed
  in purely AI-generated elements.
- For every externally sourced icon, record the author, source URL, exact source
  revision or creation date, and compatible license in this file before adding it.
- Do not represent the existing AI-generated icons as part of an external icon
  collection.
