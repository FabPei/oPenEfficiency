## What does not automatically follow

Redistribution does not require changes to be contributed back to this project's GitHub repository. The source obligations depend on how the software is conveyed; a public GitHub upload is not the only permitted method. A recipient who receives the source may redistribute it under the license.

Merely using the add-in to prepare a presentation, including paid client work, does not put the presentation under AGPL. Material copied from a separately licensed asset collection retains its applicable terms.

## Modified software used over a network

Section 13 adds a source-offer requirement for a modified version that supports interaction with users remotely through a computer network. Those users must be prominently offered the corresponding source of that version, free of charge. This is a separate rule from ordinary local use of the PowerPoint add-in; internal desktop use does not by itself mean the source must be published on the Internet.
